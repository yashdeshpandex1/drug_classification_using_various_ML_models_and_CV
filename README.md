# Drug Classification using Various Machine Learning Models and Cross-Validation

A machine learning project that explores and compares multiple classification algorithms to predict drug types based on patient data. This repository uses the **Drug200 dataset** and implements preprocessing, model training, evaluation, and cross-validation.  

> 📊 The goal is to find which models perform best for drug classification and to provide an easy-to-use baseline for further experimentation.

---

## 🚀 Features

✔️ Data loading, preprocessing, and exploration  
✔️ Handling categorical & continuous features  
✔️ Training and evaluating multiple ML models  
✔️ Cross-validation for robust performance assessment  
✔️ Model comparison with accuracy and detailed metrics  
✔️ Notebook with visualizations & results  

---

## 🧠 Dataset

The dataset **`drug200.xls`** contains information on patients and the type of drug prescribed. Typical features include:

| Feature | Description |
|---------|-------------|
| Age     | Patient age |
| Sex     | Gender |
| BP      | Blood Pressure level |
| Cholesterol | Cholesterol level |
| Na to K ratio | Sodium to Potassium ratio |
| Drug    | Target class label |

📁 The dataset file `drug200.xls` is included in this repository.

---

## 🛠️ Models Included

This project builds and evaluates the following machine learning models:

- Logistic Regression  
- Decision Tree Classifier  
- Random Forest Classifier  
- K-Nearest Neighbors (KNN)  
- Support Vector Machine (SVM)  
- Naive Bayes  
- *(Optional)* Ensemble or advanced models as needed  

Each model’s performance is evaluated using cross-validation for reliable comparison.
